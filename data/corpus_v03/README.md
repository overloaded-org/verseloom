# v0.3 真实文本的二字片段复原数据

这是客观的**原文复原诊断**，标签表示冻结来源实际写了哪些字。它不提供文学质量优劣标签，不把其他措辞判作坏诗，也不认证这些文本全都属于合律的五律或七律。

## 来源与冻结

来源为 `chinese-poetry/chinese-poetry` 的固定提交 `b8594f81a89752241442f2ce267d6f66f96704ee`。使用 `全唐诗/poet.tang.0.json` 至 `poet.tang.9000.json`，间隔1000，共10个分片。第0分片复用 `../audit_sources/tang_0.json`，其余9个原始文件保存在 `raw/`。实际总数为 **10008条**，部分源分片超过1000条，不强行改写为10000。

源URL、原字节SHA-256、文件大小、记录数和代码许可证身份均在 `source_manifest.json`。源仓库提示互联网采集及文字错误；该版本不构成逐诗校勘本。取得源码的日期为2026-10-29，构建时间见 `freeze.json`。

处理配置、来源SHA与构建代码SHA在数据处理前写入 `freeze.json`。`build_manifest.json` 记录所有派生数据SHA。本地冻结可供复算，不等于外部预注册。

## 筛选与整族切分

按中文句读 `，。！？；` 拆分，严格收取8行、每行5或7个CJK统一/兼容汉字的正文，保留原始Unicode码点。不做繁简转换、异体合并或无出处改字。不符合形状者6377条，包含其他正文字符者14条；共3617条接受记录。

1. 全文逐行相同的文本先去重，保留全部出处及来源中的作者/题名。38个完全重复组共消除38条重复，得到3579首不同文本。
2. 对不同文本，任一完整行相同，或行内字符二字组集合Jaccard至少4/5，即连边。
3. 连通分量形成诗族。这里的诗族是明确表层关系的操作定义，不声称已经穷尽所有异文或题组关系。
4. 对稳定诗族ID加固定盐后取SHA-256哈希桶，0—6999为train，7000—8499为dev，8500—9999为test。比例是预设分配概率，实际数量照实报告。

全部213个满足条件的不同诗对关系保存在 `family_edges.jsonl`，每条保留共享行和适用时的Jaccard分子、分母；其中213对共享完整行，87对也达到Jaccard阈值。得到3382族，最大4首。完全重复的源记录成员另见 `exact_duplicate_groups.jsonl`。

| 分割 | 去重诗数 | 诗族数 | 复原任务数 |
|---|---:|---:|---:|
| train | 2502 | 2373 | 10008 |
| dev | 547 | 508 | 2188 |
| test | 530 | 501 | 2120 |

同作者可能横跨分割。本轮不属于作者留出评测，固定前10个分片也不是全唐诗的随机样本。

## 任务与可见信息

每首生成四道题，分别取四联的下句，遮蔽下句首两个字。二字片段是固定字位跨度，**不声称进行了词法分词**。上句和下句其余字位为共同题面；原文首两字为独立标签。

`tasks.jsonl` 每行主要字段：

```json
{
  "task_id": "poem_...:couplet0",
  "poem_id": "poem_...",
  "family_id": "family_...",
  "split": "train",
  "length": 5,
  "couplet_index": 0,
  "upper_line": "上句五个字",
  "masked_lower_line": "□□余三字",
  "lower_suffix": "余三字",
  "start": 0,
  "mask_length": 2,
  "target": "原文",
  "author": "仅审计",
  "title": "仅审计",
  "source_refs": []
}
```

上面字符串只示意字段，不是实际诗句。`wordconv_lab.corpus.model_view()`提供严格允许列表：只输出length、upper_line、masked_lower_line、lower_suffix、start和mask_length。不得向模型或候选检索器输入target、作者、题名、诗号或完整原下句。训练时可以使用训练分割的target作为监督事实；dev/test的target只供评价。

`poems.jsonl` 保留全诗用于来源和训练许可审计，不能让评分器从题号回查隐藏答案。

## 训练词表与候选

`vocabulary.json` 仅统计训练分割全诗正文，最低字符频次2；含3067个原字形，索引0保留`<UNK>`，`tokens`和`character_to_id`给出确切映射。

`candidate_spans.json`只统计训练集偶数句首二字，按五言/七言分开，最低片段频次2。五言1317项，七言97项；每项含text、count和训练来源诗号。候选中的所有字均在训练字符词表中。

这个文件只是全候选词表，不是每题的检索结果。任何dev/test原文都不能为了保证命中而注入候选池。所有OOV任务仍完整保留；实际候选召回及最终准确率应另行计算。

| 分割 | target在对应训练候选词表内 | 全部任务 | 词表覆盖率 |
|---|---:|---:|---:|
| train | 3887 | 10008 | 38.84% |
| dev | 426 | 2188 | 19.47% |
| test | 418 | 2120 | 19.72% |

这些是词表覆盖诊断，不是模型分数或检索召回。没有据此修改分割、最低频次或筛选范围。

## 复算

从项目根目录运行：

```bash
python scripts/build_corpus_v03.py --check
PYTHONPATH=src python -m unittest discover -s tests -p test_corpus.py -v
```

`--check`验证冻结源与代码身份，重新构建所有派生输出并逐字节比较；不下载、不覆盖证据。首次构建拒绝覆盖已有freeze。测试覆盖共享行与近重复跨分割、未知词保留、训练集候选限制、完整下句泄漏和显式UNK。

## 未解决的边界

原字形保留意味着异体/繁简不同的重复可能尚未发现；同一诗题组也可能没有足够表层重合被连接。没有声调或韵部信息进入此复原标签，不会为方便套格捏造语境读音。实验结果最多说明给定语料与候选机制下的原文复原能力，不能直接转译为文学质量提升。
