# v0.4 独立确认语料

本目录用于原文二字片段复原的独立确认。这里没有训练新评分器、构建候选词表或计算原文命中率。

## 固定来源与筛选

- 来源：`chinese-poetry/chinese-poetry`，固定提交 `b8594f81a89752241442f2ce267d6f66f96704ee`。
- 固定十个分片：`全唐诗/poet.tang.10000.json` 至 `poet.tang.19000.json`，步长 1,000。
- 政策、代码和旧排除集 SHA 在下载新分片之前写入 `freeze.json`。完整 URL、获取时间、字节数和 SHA 见 `source_manifest.json`。
- 原始记录 10,003 条；八句等长五言／七言、全 CJK 形态筛选通过 4,286 条，精确去重后 4,284 首。没有变更原 Unicode 字形。
- 新旧文本联合建图：精确相同文本合并，共享整句或句内二字集合 Jaccard ≥ 4/5 时连边，再求传递连通分量。
- 旧排除集包含 v0.3 的全部 3,579 首，覆盖 train 2,502、dev 547、test 530。任何与旧诗同一连通分量的新诗都被排除，包括经其他新诗间接连接者。
- 共排除新诗 183 首，其中 38 首文本精确见于旧集。其余 4,101 首组成 3,997 个可选新诗族。
- 对可选诗族，按 `SHA256("versematrix-confirmation-v04-20261029" + ":" + family_id)` 升序、再按 `family_id` 升序，取前 512 族，整族保留。不根据任何模型结果增补、换分片或重抽。

## 证据文件

- `raw/`：十个固定分片的完整原始字节。
- `new_unique_poems.jsonl`、`new_exact_duplicate_groups.jsonl`：新来源解析与精确去重结果。
- `joint_family_edges.jsonl`、`components.jsonl`：旧新联合关系与连通分量，包含旧成员、新成员和选择顺序。
- `selection_records.jsonl`：每首新诗的排除／未选／选中决定；该文件不含模型分数。
- `poems.jsonl`、`tasks.jsonl`：本轮实际确认数据。
- `audit.json`、`build_manifest.json`：计数、断言及派生文件摘要。

未选中的新诗仅作为筛选证据留存，不用作本轮开发集。已有旧数据和脚本均未修改。

## 复现

已经附带原始来源时，完全离线重建并逐字节核验：

```bash
python scripts/build_confirmation_v04.py --check
PYTHONPATH=src python -m unittest discover -s tests -p test_confirmation.py -v
```

从空的项目内输出目录重新制作时，按顺序执行 `--freeze`、`--fetch`、默认 build；同一轮必须保持相同的 `--out`。已完成的默认目录拒绝覆盖，只能使用 `--check`。

## 解释边界

形态筛选不是严格律诗认证。这里使用表面文本关系建立诗族，不等同于完备的版本学去重；异体字、繁简字和未识别版本仍可能漏检。作者可以跨旧数据和确认集，选中作者中有 24 位也见于旧集。本数据不是作者留出评估，也不是全部古诗的随机样本。原文复原率衡量与给定文本的一致性，不能代替文学优劣评价。
