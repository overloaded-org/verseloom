[`chinese-poetry/chinese-poetry`](https://github.com/chinese-poetry/chinese-poetry)
repository at fixed commit `b8594f81a89752241442f2ce267d6f66f96704ee`.

`source_manifest.json`; no source text was normalized.

The repository license is preserved in this project at
`data/audit_sources/poetry_LICENSE` (SHA-256

Each downloaded-source record points to that file. The original source record
indices, source identifiers, author and title are retained with the parsed
poems for attribution and edition checking.

historical pronunciation, authorship, textual correctness or literary quality.
