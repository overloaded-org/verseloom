# 冻结数据源快照：仅供审计

这些文件来自两个公开仓库的明确commit，逐文件身份见manifest.json，各仓库许可证随包保存。未训练模型，未建立正式benchmark，未生成任何诗歌质量金标。

复算命令：`python scripts/audit_sources.py`。权威运行输出在项目根的 `results/source_audit.json`。

注意：按(section, rhyme_group)去重后才统计“多个韵部归属”。同一韵部列表中的重复字符不能算作两个读音。本轮独立复算得到1823个多归属字符。

原文不变。没有自动繁简转换、语境读音消歧或全库诗体判定。8×5与8×7只是形状候选；此1000条分片不是随机抽样。

平水韵候选表缺上声“三讲”，不能直接作为完整硬约束词典。原文件被保留是为了使这个缺陷可复核。
