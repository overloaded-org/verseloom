# SP-02：从两副中联扩展到全诗

**决定：不升级 Pages 默认生成器。** 现有通用接续模型容易认出中联的下句，却不擅长区分两副中联谁先谁后。新训的联序模型在七言上提供了一个有限的正结果；五言尚不稳定。两者都是对来源文本的识别任务，不是生成诗质量评分。

## 为什么此前只看中联

`train_continuation_ranker.tasks` 的通用训练目标是第2、4、6、8句，不是全七个过渡；`evaluate_middle_couplet.select_rows` 则只取第4、6句。原始对齐特征也只在这两个句位开启。上轮是为了定位对仗失效的窄实验，其数据不能回答全诗是否连贯，也不能把中联优势说成模型自己发现了哪些位置更重要。

## 全句位检索：保持模型不变

复用 `793c3ee` 的训练产物；本地逐项匹配原CI的64个特征用例、5,856道旧检索题的全部候选身份及两套分数（容差1e-10）。开发集1,464首、1,402个不同诗族；每首8个句位、1个尾联条件任务、1个联序任务，共14,640条记录。按诗族平均，平局按并列首位数分摊。没有读取test_reserve正文。每个句位的16个候选来自不同诗族、句长和句位相同；优先匹配句末韵部分桶，数量不足回退，相同未知桶也不是读音认证。候选组成和回退次数均在记录中。

下表为冻结**通用学习评分**的首位命中率，不是上轮中联专用模型。第1句是给定原第2句的逆向识别；第2至8句给定真实前文。随机选择是6.25%。开篇逆向识别不能与从空白起笔等同。

## 尾联是否接得上前六句

同一组16副完整候选尾联，不拆散第7、8句。A只评候选内部的7→8；B用同一通用模型评前六句→7，再评前七句→8，取两项原始分之和。五言原尾联命中率5.72%→8.54%，差+2.82个百分点（逐诗族配对95%区间+0.95至+4.77）；七言6.78%→7.56%，差+0.78个百分点（−1.02至+2.71）。这是给模型提供前文后的检索差异；不证明它写出了自然收束，七言改善也不确定。

## 联序实验：不改一个字

A、B含完全相同的八行，首联、尾联和两副中联的内部次序均不变。唯一区别是两副中联整体互换。正例由原诗顺序给出，二选一随机基准50%。冻结通用模型对七个接续的原始分求和。新增实验用同样的每步8个语料关系特征，按位置排列为56维，以真序与交换序的特征差训练线性配对模型；没有词面白名单、题材或诗意模板。另只保留2→3、4→5、6→7三处训练独立对照。新训练用五、七言各1,024个不同训练诗族，合计2,048；与开发诗族无交集。没有按开发成绩选择权重。

| 原诗联序首选率 | 五言（792首） | 七言（672首） |
|---|---:|---:|
| 冻结通用模型，七处得分相加 | 49.92% | 48.69% |
| 新训联序模型 | 53.45% | 55.69% |
| 仅用三处跨联过渡训练 | 48.99% | 53.35% |
| 新训联序模型，换成别首诗的首尾联 | 52.81% | 51.46% |

新训与通用的配对差：五言+3.53个百分点（95%区间−1.60至+8.56），七言+7.00个百分点（+1.15至+12.50）。对新训七言模型，真实首尾相对异篇首尾差+4.23个百分点（+0.23至+8.15）。异篇对照来自不同诗族、同句长且没有共用原句，但未严格匹配韵部、声律或题材，不能单凭它把差异归为意脉。以上均为已反复使用的开发集区间，按诗族重采样2,000次，未做多重检验校正。没有独立文学评分、没有生成质量改善声明、没有写入浏览器权重。
