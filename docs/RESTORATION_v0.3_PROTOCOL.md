# v0.3 原文复原先导实验

本轮承接v0.2有限结构求解，学习局部组合评分。它是客观原文复原诊断，不替代v0.1正式H-C的同感受野强对照与独立文学盲评。

## 数据和问题

固定 chinese-poetry 提交 b8594f81a89752241442f2ce267d6f66f96704ee 的前10个分片。接受纯CJK、八行等长5/7字文本，保留原Unicode字形。这是形状条件，未逐诗认证为合律五律/七律。

在切分前，将全文相同、共享完整诗句或行内二字组Jaccard≥0.8的文本连接为诗族。整族按固定哈希70/15/15阈值划分；实际数量由数据决定。表面分族不能穷尽异文，作者可跨split。

每首四联分别出题：上句完整给定，下句开头两字遮蔽，保留下句后缀。目标是该冻结来源中的原文二字片段，不是其他表达的优劣标签。二字跨度不等于词法切分。

字符表与候选片段均仅用train，最低频次2。dev/test中答案不在词表或候选池的题全部保留，计为未命中。允许列表输入仅含句长、上句、下句可见后缀、mask位置与长度；没有target、完整原始下句、题名或作者。

## 候选与三个比较对象

统计提议器为双向插值字符1/2/3-gram，权重0.1/0.3/0.6，Lidstone alpha=0.1；加同列下字给定上字的平滑统计，权重0.5、先验强度5。所有参数均在神经评价前固定。它按可见查询对训练候选词表打分，每题取前16个，再以字典序存放。

所有评分器重排同一候选池，并按候选字典序处理同分。主池由统计基线提议，结论必须限定于该池；分别报告训练词表覆盖、top16池召回、全题top1和覆盖题top1。

比较对象为：上述统计基线；可训练宽3局部卷积（12通道）；可训练宽1消融（20通道）。后两者共有8维字符embedding及4维固定行列/句长/mask特征，核心参数744/760；宽1保留上下句对齐，去掉横向邻位作用，不称为同感受野注意力对照。

当前可训练模型保持局部tanh后按位置平均，再线性读出；这不同于经典文本CNN中的max-over-time pooling。固定字位特征使已训练宽3评分继续满足局部可加分解。

## 训练与选择

三个种子0/1/2；每种子两个模型。只用原文目标处于训练候选词表的训练题学习；训练池含真实训练正例、3个统计困难负例、4个不重复随机负例，共8个。训练正例的加入是监督学习的一部分；dev/test绝不注入答案。训练池与评价池分布不同，作为限制报告。

每次运行400次真实optimizer updates，batch32，累积步数1。Adam使用beta 0.9/0.999、epsilon 1e-8、lr 0.003、解耦weight decay 0.0001、global gradient clip5。每个种子两个模型共享候选及抽样schedule。

每100次更新只在dev评价。以全dev题的诗族等权top1选择checkpoint，未覆盖题计0；同分选较早的checkpoint。记录每次真实更新、12800次任务曝光，以及实际不同题/诗族曝光数；不把抽样曝光换算成完整训练若干轮。

统计提议器会预先处理test的可见查询以冻结池，但不读test目标决定池。六个神经模型的checkpoint及文件SHA冻结后，才计算神经test评分与正式准确率。本地冻结不是外部预注册。之后这些test题即已暴露。

## 指标与门槛

主指标：每个诗族内先平均所有题，再对诗族等权平均。另报题目micro准确率、分句长准确率、候选覆盖及覆盖题准确率。

同架构三种子先等权平均每题正确值，再计算族内配对差并bootstrap5000次，报告95%区间；种子单项结果另列。该区间以这三个固定种子为条件，不估计无限随机种子总体不确定性。

先导晋级条件：宽3模型相对统计基线、宽1消融均提高至少2个百分点的族宏准确率，且各自配对区间下界>0。即便通过，也只通过原文复原先导门，不能当作文学质量改善。

## 二字约束与精确DP

二字候选是完整片段，不可拆成独立字位后允许池外交叉组合。在第一个局部因子加入成员约束：下句第0、1字拼接必须属于原候选池，否则负无穷。其作用范围仍为相邻两列，因此原宽3链式DP可精确求解。

预先指定每种句长按task hash排序前24题，对三个选定CNN分别与原池完整枚举核对，共最多144次。该核对验证已训练数学目标及候选约束，不评价文学质量。

## 真实读音的独立轨道

训练二字片段另关联106部参考，保留每字所有候选、未知与校勘议题。关联数据不进入本轮检索或模型特征。所有记录仍需语境复核，单一字—部候选也不自动成为读音金标。
