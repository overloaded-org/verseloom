# 语料自组织 v1：不再由助手预填诗意

入口：`induced.html`。它是独立研究模式，不覆盖原 `composition.html` 或 `quality.html`。无提示词、题材、季节、语义类别、事件脚本或固定句输入；只接收诗体、种子和搜索/对照参数。生成在浏览器 Worker 内运行，原始输出可导出。

## 这次究竟改了什么

旧词组生成依赖助手编写的内容词表、义项类别、动词论元表和句法骨架。新构建器不读取这些文件。它只读取原训练分割、新 train_candidate 分割、冻结历史字书、平水韵参考及形式声律模块。

1. 从训练诗中枚举一至三字片段；多字片段至少见于3首训练文本。没有手写的内容白名单、停词表或“应当写战争”的配额。
2. 对所有可能的分段做前向/后向概率计算，执行4轮 unigram EM；再以 Viterbi 分段，累计接续、三段接续、字位、句首和句尾统计。分段是统计假设，不是已认证的古汉语分词。
3. 自动累计同诗共现、相邻句方向关系和中间联同跨度对应。保留计数及稀疏邻接关系。不把共现称作因果，不把相邻句称作事件链。
4. 以声律矩阵限制词段拼接；在多个首句分支上完成八句后比较整诗。候选句在运行时构造，不从预写整句库抽取。多分支/邻居/词表上限是计算预算，不是内容主题。
5. 两个模式共享同种子候选搜索：local仅句内统计，relations另加跨句关联评分。图上的边可以影响选择，但不是必须使用某个词或必须讲某段故事。

没有内容预填不等于没有人工设计：语料范围、词段长度上限、概率模型、评分权重、声律规则和搜索预算仍是明确的工程假设。本版并未“发现唯一律诗算法”。

## 读音与对仗边界

不调用旧手写的义项读音规则。保留字书所有候选，仅当字书与平水韵候选的P/Z判断一致才准入；韵脚另要求唯一平声韵部。`selectedEntryId=null`，`contextuallyCertified=false`。同平仄的多读音仍未消歧，不能用机械通过冒充语境读音确认。

中联对应是从语料学习的软评分，而不是旧版手写角色的硬匹配。本实验因此**不提供严格对仗保证**。原模式保留作对照。暂未学习人物共指、事件因果、真假陈述或可靠的篇章语义。

## 本地开发实测（不是独立盲测）

13,810首训练文本：五言8,486首、七言5,324首。发现50,271个候选词段，音韵筛选与预算后准入10,000个，其中一字2,630、二字7,055、三字315。没有指定任何内容词。最终统计资产18,136,797字节，由固定来源构建；不将生成资产提交进Git。

固定种子 `[0,1,42,20261030]`，两种诗体、两个模式，共16次运行，16次成篇。8组配对的候选池指纹全部相同；最终诗稿只在2/8组改变。每种诗体的relations模式在4个种子中得到4首不同诗稿，八个位置均有变化。这些小样本描述不保证任意种子不重复。

独立于JS搜索的Python输出核对检查16首、768个字位、509条接续记录，全部通过声明字数、平仄、同部韵脚、重复限制、训练原句排除和原始出处检查。它不是独立文学评审，也没有为语境读音或工对背书。

10项Python测试、7项Node测试本地通过。初始Node测试错误地要求某个种子在关掉图评分后一定换诗；实测未换诗，因此该假设被撤回，测试改为核对候选池不变、图分数确实参与，不再强制每个干预都换输出。没有为使实验显著而挑换种子；2/8的负结果保留。开发时曾检查更早的实现输出，本批不冒称未见盲测。

## 原样例：relations，五言，seed=0，variation=0.8，beam=16

> 客散青天字，松花滿石壇。  
> 憐君人獨立，此別淚流寒。  
> 靜引仙官去，因循草木殘。  
> 等閑桃杏落，日夕視雲端。

这是声明种子列表的第一首，不是从样本中挑出的佳作，没有人工改字。“客散青天字”等语义仍生硬；出现人事或情绪不等于事件叙事已经成立。独立文学评分数为0。

## 复现

先运行原项目的bootstrap，得到含 `cache/` 与 `run/` 的目录；Pages流程复用 `output/phrase-input`。

```sh
python scripts/build_induced_model.py --bootstrap output/phrase-input
python scripts/build_induced_model.py --bootstrap output/phrase-input --check
python -m unittest discover -s tests_induction -v
node scripts/evaluate_induced.cjs output/induction-pilot
INDUCTION_REPORT=output/induction-pilot/report.json node --test tests_induction/engine.test.cjs
python scripts/audit_induced.py --bootstrap output/phrase-input \
  --input output/induction-pilot/outputs.jsonl --output output/induction-pilot/audit.json
```

初次数据加载较大。界面仅加载小型元信息，大模型统计只进Worker；没有新增模型API或外部推理服务。真实Safari/Chrome兼容性未在本地核验。Pages在发布后下载同一构建的6个资产核对SHA并运行五言、七言与复现；这仍不是浏览器按钮测试。

## 来源与相关研究

数据与既有项目相同：chinese-poetry固定提交（MIT）、tshet-uinh-data《广韵》固定提交（CC0）、平水韵参考（CC BY-SA 4.0），沿用各自许可与来源通知。源文本为形状筛选材料，不是严格律诗金标。

可比较的研究方向是无预给词表的古诗词发现：[TopWORDS-Poetry, EMNLP 2023](https://aclanthology.org/2023.emnlp-main.205/)；自动选取既成诗句线索的生成研究：[Salient-Clue, CoNLL 2018](https://aclanthology.org/K18-1024/)。本实现是自写的统计对照，不是这两篇论文的复现，也没有借用它们的质量结论。

**本轮结论：移除了人为内容词表和诗意框架，并验证了数据关联确实能介入选择；尚未验证文学质量提升。下一项研究应针对句法与篇章的学习效果，不应重新用手写“家国→离愁”路线掩盖缺口。**
