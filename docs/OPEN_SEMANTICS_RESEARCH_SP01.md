# VerseLoom · 开放语义研究 SP-01（2026-10-30）

## 目标与反证

研究问题不是“能否把更多名词塞进原SVO模板”，而是：在**不提供主题、不固定任何句子**的条件下，词义事件图能否产生可复现且不局限山水的五律、七律，同时不损害可验证的声律与中联结构。

**目前不是成功结论。** 词项准入依赖训练语料出现和有出处的历史读音；新增的战争、人物、情感词汇可能被大量拒绝。已有模型只支持有限句法框架，且对仗检查以槽位相等为主。生成通过不等于诗歌质量通过。

## 第一实验：验证候选真的进入引擎

从 `docs/COMPOSITION_V2_BUILD.json` 提取 admittedByKind、rejectedLexemes，并与上一冻结构建比较；新增分组中逐词统计准入/拒绝原因。**不能用源词表中的词数代替可生成词数**。所有失败和无解均计入分母。词项/义项/读音仍是助手策略，不标记为独立金标。

## 第二实验：关系图驱动的句法

在不改变声律矩阵的前提下，建立可枚举、可审计的 typed event edges：
- Agent–action–patient/recipient，例如人物→守护→家国、人物→寄→书信。
- Agent–mental-state–object，例如人物→念→故乡；不将“念”当成物理动作。
- Event–cause/consequence–event，例如征戍→别离→思归；边的出处与置信度分别记录。
- Contrast/temporal transition，例如昔/今、功名/身世；禁止将同一事件换词重复当成篇章推进。

每条边有来源、义项、论元类型、候选读音及独立复核状态；**不存储或预写任何完整诗句**。允许多个句法实现，而不是把每条边映射到一条固定句。先在五言实验模式试验，再迁移七言。

## 第三实验：独立对照

冻结同一训练诗族、韵表、随机种子、起式和搜索预算，比较：
A. 现有景物倾向SVO生成；
B. 只扩充词汇但仍用SVO；
C. 词汇扩充+事件关系图+篇章状态。

每种五言/七言至少64个固定种子；自动无解也必须记录。对照指标分开报告：
1. 机械通过率（字数、韵脚、平仄、来源、无固定句）。
2. 非山水事件覆盖（有真实人类施事/受事及事件关系，非仅出现“故国”等字眼）。
3. 同诗的事件推进、逻辑矛盾、主题连贯和语义重复；用匿名人工对照评审，不把自定义评分当独立结论。
4. 语境读音未决率、对仗结构可解释率、真正专家复核率。
5. 诗句/首句重复、整首重复与训练诗句撞库率。

保留诗族级dev/test隔离，开发样本不称盲测。不能因为C无解多就删掉失败样本；不能靠手改诗或预写模板提高指标。输出JSON应包含事件图、每句词项来源、候选选择、读音未决项和拒绝原因。

## GO / STOP

GO：同预算下非山水事件覆盖有明显增长，机械约束不退化，人工盲评至少不劣于B，且没有固定句或训练集泄漏。
STOP：仅有非山水词出现而无事件关系、失败率明显上升、或通过人为锁句/调整读音来维持结果。STOP时保留现有线上版本，继续研究，不宣称已突破。
