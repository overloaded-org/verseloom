## 实验设计

两种诗体各8个固定种子（0、1、2、3、42、43、44、45），两种评分（原统计关联 relations；训练语料学习的 learned），探索强度0.8、beam宽度16、不传入近期历史。两臂候选池一致，完成后逐字比较八句。另以种子0、2、42、43，在同一模式下把beam宽度16改为8，检查搜索预算敏感性。

这是**开发集诊断**，不是盲测。程序未提供固定诗句、预填主题或情节。读音使用未完全语境消歧的历史候选。

### 独立于生成器的狭义任务

在开发集“从16条候选中找回真实来源接续句”的任务上，family-average R@1：
- 五言：16.885% → 18.179%（+1.294个百分点）。
- 七言：19.435% → 21.573%（+2.137个百分点）。
- 按诗族配对的总体均值差：+1.648个百分点，95% bootstrap区间约[+1.054,+2.186]个百分点。

**这些不是对仗正确率或文学质量分。** 正例仅是原诗相邻句，负例是其他诗的句子；任务存在候选构造与语料风格的捷径。不能据此证明诗的情感、时空或句法连贯性提升。

## 关键反证

1. 学习评分只使16组中的4组换稿，且这4组的**八句全部改变**，无法把收益归因于某个中联或尾联。
2. 将搜索宽度从16降到8，16组里10组换稿，且9组改变韵部：**搜索路径选择高度敏感**，学习评分的效应可能被搜索策略淹没。
3. 当前所谓中联“alignment”是词段位置/共现证据，不包含经过独立复核的词性、句法角色和语义工对标注。机械合格不等于七律合格。
4. 用户提供的四首七言批评指出系统性失败，但缺少与这次运行一一对应的诗稿/种子/原始收据，因此不能把它们直接计作本轮四首金标。
5. 本轮**独立文学评分为0**，无法证明句法顺畅、意脉连续、用典恰当或尾联自然。

## 决策与下一实验

**当前判定：Research GO / Production STOP。** 继续研究，但不把SP-02诊断宣称为工对修复，也不替换线上默认算法。

下一次必须先做可识别的干预：固定韵部、起式、前六句与候选池，仅重排尾联；对中二联则固定上下文与候选池，比较独立选句和联合选联。控制相同候选数和beam预算，逐条保存无解与源诗撞句。并对真实程序输出做匿名人工评价，区分“像原诗”与“真正写得通顺”。

**数据由算法归纳；不写入固定题材、固定句子或预设故事路线。**
