# 词组质量实验台：可运行闭环，不冒充文学认证

本版新增 `web/quality.html`。原五言/七言自由组合生成器保持原样，首页增加入口；不在尚无独立文学评价时偷偷替换旧版。新入口也不使用固定句、首句锚点、预存完整诗或失败兜底。

## 从词组到八句

不再在冻结整句池中选择：`data/quality_v2/policy.json` 仅包含一字/二字词组、义项策略、词类、语义类别及谓词选择条件。浏览器按模板实时组合词组。固定的是关系和有限词汇，不是任何输出句子。

五言使用 N2–V1–N2 或 L2–N1–D1–I1；七言使用 L2–N2–V1–N2 或 T2–L2–N1–D1–I1。这些是有限的操作性句法框架，不是古汉语全部语法。中间两联在共同的词组边界、词类、角色与名词语义类别下**联合构造**；同位同词、同位同字都被拒绝。谓词还须满足声明的主语/宾语类型条件，避免把任意名词塞给任意动词。

搜索先处理候选最少的句/联，不以第一句作为锚。所有分支共用 beam 预算；在选每组句/联后，前向检查剩余句位与韵脚的可行性。保留多个分支，八句完成后才按种子选完整路径。它是有限词格上的启发式搜索，不保证全局最优，也不承诺任意参数一定有解。

同源数据、版本、诗体、种子、参数和历史可重放。缓存只省计算，不改变决策或计数回执。季节和昼夜由整诗共享，探索不放宽字数、声律和重字规则。用现有、有出处的 `common_prefix` 窄变式，而非一概“奇数位自由”。韵脚不重复、句内不重字、全诗每字最多两次。

## 数据确实参与了新模式

只读旧 `train` 及新增 `train_candidate`，不解码 dev/test/reserve 文本来训练统计。总计五言8,486首、七言5,324首形状候选。它们不是经过逐首审核的严格律诗金标。

511条配置记录去重为499条词义/角色策略，374条有训练出处并满足当前音韵准入，125条被排除；保留具体原因。语料出现次数、最多三条原诗字位出处、所有来源散列都进入编译产物。整句在训练文本中完整出现则禁止输出；这不等于全诗库原创性认证。

数据从固定版本构建，不下载或执行第三方脚本。词类、义项、语义选择与生成框架由助手编写，明确是操作策略，不是独立金标。语料出处证明词组出现过，不能证明每次重组都自然。

## 历史读音与释义参照

`GlossGraph` 只处理上游明确说明的相邻记录“上/下”边，保留链与原文；不把释义目标的反切/读音复制覆盖到原字。循环、越出小韵、未知参照形式、缺邻居都报告，不能无限追踪或猜测。

生成词的拟用义项/读音策略在匹配模板**之前**确定。先从《广韵》条目与固定义项策略取声类，再在既有平水韵表同声类中要求唯一候选；不为通过平仄临时挑读法。平、上、去、入四类分别处理，而非只看P/Z。重叠义项、无法确定或出处不匹配的策略不准入。

这仍不是完整的《广韵》到平水韵历史映射学说，更不是独立的语境读音认证。单个字书条目也可能多义；选定词义与词类仍有助手解释成分。返回值保留 `contextualPronunciationCertified=false`，页面展示证据和策略而非假“已审定”。

固定《广韵》25,336条记录中，25,143条可终止于完整参照链或本条释义，193条涉及参照循环，保留未决。全部400组开发任务均生成词组候选格及逐字音韵参照记录，**机器处理完成不等于标注审定**；原400条任务和4条助手草案没有被改写或升格。

## 可核验边界

- 结构对齐：可核验框架、词类、语义类别与字位规则；不等于专家认定的工对、非合掌、典故协调。
- 文学质量：加入句法、语义搭配、共享场景和收束偏好；没有独立盲评，不能仅用自己的代理评分宣布文学质量已经提高。
- 语境读音：证据和拟用策略已接通；全部语境经独立复核的数量仍为零。
- 旧生成器保留；新模式明确标“实验”，没有用新证据门槛为旧诗稿补发认证。

## 复现

```sh
python scripts/bootstrap_quality_data.py --download --cache output/q-source --output output/q-bootstrap
python scripts/build_quality_v2.py --bootstrap output/q-bootstrap --output output/q-v2
python scripts/build_quality_offline.py
python -m unittest discover -s tests_quality_v2 -v
QUALITY_EVIDENCE_DIR=output/q-evidence node --test tests_quality_v2/engine.test.cjs
python scripts/build_web_demo.py --output _site
```

输出目录不得已存在；词组数据可确定性重建。`annotation_analysis.jsonl` 保存400个任务的机器候选分析；`dictionary_references.jsonl` 保存有释义参照的字书记录及链接；`excluded_words.json` 保存准入失败；`report.json` 和清单保存实际规模及散列。

新增16项Python证据测试、10项Node生成器测试。八种诗体×起式、种子复现、无固定句、所有句位变化、历史快照、取消、Worker一致、伪造读音/角色/结构拒绝均覆盖。种子100..107、固定一先韵的开发诊断：五言8首全异，各句位不同句数8/4/7/8/7/6/6/5；七言8首全异，为8/8/6/7/8/7/8/7。这些是回归材料，不是独立文学评价。

真实浏览器与远端部署的结果另外保存；不得把Node/DOM测试写成Safari/Chrome网址兼容性已全部验证。全量三项目标的独立审定尚未完成，质量主线Issue #1应继续开放，而不是以工程测试通过替代文学验收。
