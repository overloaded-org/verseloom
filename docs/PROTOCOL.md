# 诗矩验证协议 v0.1

日期：2026-10-29。状态：本地设计协议；尚未开展正式诗歌训练或解封质量测试，不构成外部平台预注册。

## 0. 目标与结论等级

主目标是检验一个可运行的生成模型：**字词放置在固定位置上，声律和结构定义约束，组织算法通过替换、分支探索与反馈形成表达。** 词卷积是可独立替换的局部组合评分模块。

本项目区分四种证据：

1. 表示可用：能够无歧义地表达位置、读音、词跨度及关联。
2. 工程正确：合法性、预算、回放和数据隔离可验证。
3. 算法有效：在共同状态空间及预算下，某一更新规则改善搜索结果。
4. 诗歌有效：在独立盲评中，选择或创作的表达优于预先指定的强基线。

前一层通过不能直接推出后一层。已知文本CNN和卷积语言模型支持技术可实现性，不自动验证本项目的二维声律组织假设。[S1][S2]

## 1. 三个可分离的假设

| 编号 | 主假设 | 独立实验 | 不能据此声称 |
|---|---|---|---|
| H-M | 某个明确的矩阵状态调度策略，在相同预算下改善合法状态搜索 | 固定评分器的有限可穷举状态空间 | 矩阵表示本身必然优于序列表示；诗人脑中执行该算法 |
| H-C | 局部共享组合核，改善给定候选中的表达选择 | 固定候选重排，对比强局部非卷积模型 | 仅胜过独立字打分就证明卷积独有优势 |
| H-I | 组织方式与评分方式存在正向交互 | 2×2因子实验，共同外部质量评价 | 不同模型内部得分可以直接相减 |

结论只限于冻结的任务、数据、模型和预算；不能由一个手工合成例子推及真实诗歌。

## 2. 矩阵对象与状态

常规五律/七律采用8×5或8×7字位网格。古体诗不直接套用这套固定格律；排律与词暂不进入v0。关于近体诗的字数、声律、粘对与对仗，采用传统格律资料作为规格来源。[S3][S4]

| 对象 | 内容 | 规则 |
|---|---|---|
| X | 当前字位矩阵，每格一个字或明确的空位 | 形状固定；空位不是合法完成结果 |
| D | 各可编辑位置/词跨度的有限候选域 | 构造来源固定，测试参考答案不进入候选生成器 |
| R | 每个字在语境中的读音记录 | 一条记录同时绑定声调、韵部、释义/消歧依据及来源 |
| H | 硬约束规格 | 选定的完整格律模板、韵脚位置、全局韵部、长度与冻结内容 |
| F | 特征张量 | 字位语义、词跨度、已给定音韵条件及位置角色；不能泄漏被遮蔽目标 |
| Q | 候选内部评分函数 | 只是搜索目标，不能自动解释为客观文学质量 |
| B | 有限预算 | 尝试数、评分调用、缓存命中及真实耗时分别记录 |
| E | 事件轨迹 | 初始化、展开、非法/重复拒绝、入队、最佳解变化、终止 |

### 2.1 音韵规格的严格含义

- 先选择一个完整模板。允许的变式、拗救等必须作为有出处的完整规格或关系约束记录；不能把不同模板逐格取并集后拼出没有依据的新模板。
- 平仄与韵部必须来自同一条已核验读音记录。不得从一个读音拿平仄、另一个读音拿韵部。
- 多音字不能仅因某一读音恰好合律就自动消歧。需要上下文与来源依据；无法确认时返回 `needs_review`。
- 传统声调与韵部不能直接用普通话拼音替代。繁简转换保留原文与映射，不能覆盖原文。
- 模型使用“已给定韵部”时，只能声称条件选词能力，不能声称自主判断韵部正确。
- 对仗的词类对应可以作为特征；语义关系和诗意必须另评。词类匹配不是完整的对仗质量判定。

### 2.2 当前实现与目标规格的差别

当前 `MatrixProblem` 支持任意正整数形状与有限域；完成状态必须先合法。`check_lines` 检查调用者提供的一套模板与全局韵部，不证明模板本身具有历史权威。v0.1只检查显式读音接口，不内置正式音韵词典。

## 3. 矩阵组织算法

本轮选择一个能被充分审计的具体实现：**在完整候选状态图上保留备选分支，逐步展开邻域。**

两种调度策略共用完全相同的状态、约束和动作：

- M0 / FIFO：按发现顺序展开备选状态，邻域按固定字位顺序枚举。
- M1 / Priority：优先展开内部评分较高的备选状态；同分采用确定性顺序。

这两种策略都是已有搜索思想的具体实现。它们的区别在分支调度，而不是一个有矩阵、另一个没有矩阵。冲突优先位置调度可在后续独立版本加入，不记作本轮已经实现。

### 3.1 精确更新流程

1. 检验初始完整状态，非法则报错；两组使用同一初始状态，不额外赠送初始化修复。
2. 初始评分计入评分预算，保存最佳合法状态。
3. 依M0/M1选择下一个已知合法状态。
4. 根据共同动作表枚举单格替换及明确的联合替换。
5. 每个尝试先扣除proposal预算；重复和非法候选同样计入。
6. 合法新状态调用共同评分器；评分次数增加，进入待展开分支。
7. 分数更优时更新最佳合法状态；低分探索不能覆盖已经找到的最佳解。
8. 尝试数、评分数任一达到上限即停止；返还最佳合法状态与完整轨迹。

算法允许从先前保存的分支继续探索。本轮采用不可变状态和父指针，不宣称实现了原地状态栈回滚或崩溃恢复。

### 3.2 动作、可达性与穷举

联合动作有可能是必要的：例如两个韵脚必须同时改变，单格替换会产生非法中间态。这样的动作必须同时提供给两组。若只给M1联合动作，则是在改变动作空间，需要额外因子实验。

`frontier_exhausted`只意味着从初始状态出发的合法可达分量耗尽。全域穷举oracle遍历全部候选组合；二者只有在连通性得到证实后才能视为同一搜索空间。审计同时报告可达空间覆盖与全域最优差距。

oracle仅属于评价端，不提供给调度器。测试后的精确最优分数不能反向用于候选优先级。

### 3.3 计费与重放

所有尝试、非法拒绝、重复访问和联合替换都计入proposal。初始及合法新候选的评分计入score_calls。缓存命中仍消耗proposal；回到旧分支不返还预算。除调用计数之外，记录真实墙钟时间与峰值内存，避免把相同调用数当成相同算力。

事件保存候选、父状态、动作位置、拒绝原因、评分及计数。trace有哈希链，并可用同一输入和评分器重执行逐事件比较。trace本身不是签名，也不是完整模型身份清单；运行回执另外保存代码、权重、词典、配置与环境指纹。

## 4. 词卷积评分模块

在目标实现中，X的字位内容转为特征张量 F∈R^(8×L×d)。词语可以跨多个字位，应保留词跨度信息；不能将“一个词”误当恒定大小的一格。

局部算子采用神经网络通常所称的卷积约定，即共享权重的局部互相关：

`h[i,j] = activation(sum(W[a,b] @ F[i+a,j+b]) + bias)`

- 横向核：只在同一句内计算局部组合，不把前句末尾与后句开头当相邻字。
- 同联核：只作用于指定联的对应位置；上下句角色明确。
- 位置条件：区分句首、句尾、韵脚和联的角色；不假定所有位置具有同样职责。
- 全局关系：全篇韵部、不同联之间的关联由显式关系或共享状态处理；扩大卷积感受野并不保证硬约束自动满足。

### 4.1 本轮算子

当前原型只包含逐句宽度3的共享核、同联对应位置的核和固定读出；使用抽象token identity、合成声调/韵部及位置特征。权重随机初始化，`trained=False`。没有真实语义编码、词跨度学习和训练器。

其用途是检查边界、顺序、数值、候选共享和组织器接线，不用于比较诗歌质量。工程pointwise参照没有做参数预算匹配，不能替代正式强基线。

### 4.2 正式训练建议

首轮正式模型从审核语料自监督训练，优先采用遮蔽字词恢复；原句提供观察事实，不把合成候选标成“坏诗”。用于隐藏目标的token identity和从该目标推导的额外读音信息必须遮蔽，保留的条件只能来自题面与预先指定的格律。

建议固定同一编码器、候选打分接口、样本曝光与调参次数。工程预算上限为每模型200万可训练参数、最多2000次optimizer update、batch 32、gradient accumulation 1、5个固定种子；正式使用前由开发集计算开销试运行锁定。记录micro-step、optimizer-step、实际样本/字位曝光和耗时，不能只报告模糊的iterations。

评分模型对所有完整候选使用同一种条件评分或伪似然规则，长度归一化一致。不混用“一个模型直接看完整候选、另一模型只看前缀”的接口。

强基线至少包含：

1. 独立字位评分：弱基线，用于判断局部上下文是否有帮助。
2. 相同训练集的平滑字符n-gram：判断局部统计是否已能解释收益。
3. 同感受野、同邻接关系的局部注意力：主要非卷积强对照；参数预算控制在同量级并报告实测。
4. Locally-connected层：单独研究参数共享，分别报告等宽和近似等参数条件。

共享窗口的一层MLP可能与卷积数学等价，不能作为“非卷积强对照”。

## 5. H-M：组织方式实验

### 5.1 机制实验

使用有限可穷举空间：在8×5或8×7完整状态中，开放2至4个字词跨度，每跨度3至5个候选，最大625种组合。开发集60题、冻结测试240题；这些是设计目标，尚未生成正式题集。

题集预先分为可分离评分、局部关系评分、需要联合动作的硬约束、局部最优陷阱四类。人工合成关系题仅用于机制审计；所有标签明确为synthetic，不能进入真实诗歌质量结论。

共同预算：proposal上限8/16/32/64，主预算32；评分调用另设相同上限。两组使用同一初始状态、候选域、完整上下文、邻域顺序、动作集合、约束和缓存策略。不可隐藏优先级探测中的额外评分。

### 5.2 指标与门槛

记录合法返回率、预算内最佳分数、全域/可达最优差距、首次达到指定目标的调用数、唯一合法状态数和真实时间。归一化regret只在同一题、同一评分器内计算；最优与最差相等的题单独报告，不人为制造分母。

建议Go条件：工程性质全部通过；冻结机制集上，主预算的平均归一化regret相对M0降低至少20%，配对区间支持改善，且退化不集中于某一关键题型。阈值是项目决策标准，不是数学定律；若基线已几乎零regret，则报告天花板而非强行宣布成功。

Stop/Revise：仅在允许更多动作、更多调用或不同初始化后获胜；收益消失于共同预算；或存在非法best/预算超支/不可重放。失败只否定该调度版本的效用，不否定矩阵表示作为形式描述。

## 6. H-C：固定候选重排实验

### 6.1 任务

给定同一上句、题意/允许上下文、选定格律与韵部，从同一组完整下句候选中选择。每题目标16至64个去重候选；候选来源及其顺序在模型评分前冻结。

候选生成器只能读训练词表、题面、共同约束及预先指定语料；不可读隐藏原句，也不可保证将原句放入开放候选池。独立保留一个“参考原句恢复”诊断集，该诊断不参与创造质量的主结论。

如果采用修复任务，已给出的破损句及可编辑位置对所有模型相同；未编辑上下文可能包含原诗内容，是题面而不是训练许可。

候选池不能只由待测卷积模型产生。优先混合确定性词跨度替换、共同n-gram候选和训练语料检索，并记录来源配额。候选生成方法决定了实验外推范围，报告必须说明。

### 6.2 数据分割

先整理原诗/异文/繁简规范化视图与重复族，再整族划分。原诗所有联、掩码题、扰动题及派生样本继承同一split。原文不得覆盖。当前审计器只检查已有重复族是否跨split，不负责发现近重复。

目标规模：训练不少于5000个独立诗族、开发500个、封存测试1000个。首轮可先做开发集小样本流程试跑；若审核后数量不足，须在接触正式测试结果前更新协议版本与样本量，不能边看结果边扩样。

作者留出作为额外稳健性切片，不与随机诗族切分混为同一指标。若引入外部预训练编码器，必须单列实验，因为经典原句可能已存在于其训练材料中；不能保证无记忆污染。

### 6.3 主评价

主指标是与预先指定的强非卷积基线相比的匿名配对偏好。每题允许胜、平、负；对应1、0.5、0。所有模型相同的空候选题在评分前确定质量评价资格，并报告覆盖率。模型自身执行失败另列，不能默默删除。

至少3名评审独立观察打乱左右的输出，不展示模型名、原诗作者或参考下句；记录是否认出原句。相同输出按协议记平，须与人工评价来源分开。评审可以skip并说明原因；缺失不伪造为平局。

按源诗或更严格的重复族等权聚合，不把同源多个候选、评审或训练种子当独立样本。当前bootstrap按source_poem_id聚类；正式主样本每族最多一个源诗。多评审交叉效应及种子方差需要额外敏感性分析，当前工具未实现混合效应模型。

主门槛建议：平均偏好分p≥0.55，95%区间下界>0.50，且结构与连贯性没有预定义的实质退化。当前工具输出的配对差值δ=mean(score_a-score_b)=2p-1，因此等价门槛为δ≥0.10、区间下界>0。不能拿δ直接与0.55比较。

1000诗族、3评审是拟定评估预算，不代表已招募人员或完成标注。样本精度在开发阶段试评后、正式封存测试解封前锁定；正式测试只做一次确认，失败后再开发必须更换新测试集。

区间跨0.50应写“证据不足”。仅胜过独立字位模型，可以支持局部上下文有用，不能支持卷积优于强局部模型。

## 7. H-I：2×2联合验证

| 组织方式 | 强非卷积评分 C0 | 卷积评分 C1 |
|---|---|---|
| M0 / FIFO | M0C0 | M0C1 |
| M1 / Priority | M1C0 | M1C1 |

共同固定起点、候选域、硬约束、上下文、动作与调用预算。四组均允许保留备选分支，不能把“有回溯”只给其中一组。

先分别完成H-M和H-C，再执行联合实验。内部评分器不同，原始score不在共同量纲上；不得计算 `conv_score - unary_score` 作为交互。

联合阶段预先指定共同外部评价：可穷举机制任务使用同一个隐藏oracle；真实诗句使用打乱模型身份的统一量表。每个输出的连贯性按0至4分锚定（0不可读、1关系断裂、2基本可解但松散、3连贯、4连贯且层次清楚），除以4得到共同Q。另报配对偏好作为稳健性分析。这个量表是研究操作定义，不是文学价值的客观计量。

交互估计：`Delta_I = (Q_M1C1 - Q_M0C1) - (Q_M1C0 - Q_M0C0)`。按同一源诗聚类计算区间；当前工具未实现四臂交互的自动分析，应在运行前补齐并冻结。

正交互且主效果合格，支持组合带来额外收益。两者各自有效而交互不显著，可以独立保留两个模块，不宣传“协同效应”。

实测只有105个韵部：上平15、下平15、上声28、去声30、入声17，缺上声“三讲”。与传统平水韵106部规格不一致。[S4][S7] 此表是待修订候选来源，不能直接当权威完整词典。

表内8232个不同字符中，按去重后的(声部,韵部)统计，1823个具有多个归属。不能把同一韵部列表中的重复出现算成不同读音。繁体诗文与简体表直接查字，形状候选11312个字位仅命中7329个；这是兼容性诊断，不是合律率。

本轮保留原始快照、SHA-256、源路径与许可证，状态为 `audit_only_not_benchmark`。不把未消歧数据用于硬约束训练或诗质结论。

## 9. 工程验收

必须通过：形状/域检查；非有限评分拒绝；整数预算；所有拒绝计费；相同动作与候选；非法状态不成为best；最佳合法状态保留；同输入重放；轨迹篡改/评分改变可检出；可达性限制不被误称全局最优；跨句卷积不串接；读音属性不拼凑；未知待复核；源诗/重复族无跨split；盲评内容与比较身份绑定；无标注时不输出质量分。

本次实际测试数、代码SHA和运行版本由 `results/test_receipt.json` 提供，不手工把计划测试数写成已运行数。

立即下一项工作是G1：先建立一批带版本依据的五律种子清单，逐诗核对原文与读音，形成完整候选域；同时修订候选韵表的缺部、重复和繁简映射。初始200首仅用于数据流程与开发验证，不能充当正式独立测试或最终质量结论。
