# 文学质量、对仗和语境读音：质量研究 v1

## 决策

不再把这三项只当作展示页免责声明。新增可运行审校实验、原样输出记录和盲评包；但本轮不替换网页生成器，不宣称三项已经解决。继续禁止预写句、锁定首句和失败时返回存档诗稿。

这个切片不是新的训练模型，也不是自动文学鉴定器。`src/wordconv_lab/quality.py` 只读取程序已经产生的诗，不生成或改写其中的任何字。

## 三种证据分开

1. **文学质量代理**：统计 2+3／4+3 词块交界处的一个二元、两个三元字串在训练集中的支持数；增加有限词法／句法草案分析。训练未出现不等于不合语法，更不等于坏诗。没有用开发／测试诗更新统计。
2. **对仗结构**：对上下句分别分析，再对齐词类和跨度；未知词不补标签。多种句法解释不得因某一种“恰好能对上”就被消歧。词性、跨度吻合只报告“草案规则下结构对齐”，不冒充语义工对、典故协调或非合掌认证。草案词类由本次助手标注，没有独立校对。
3. **语境读音**：逐字保留参考表所有候选韵部及原表行号。同为平声／同为仄声但属于多个历史韵部的情况仍为未消歧。加入五个教育部词条的现代读音提示；绝不把现代一二声直接映射古平声，或用现代拼音选历史韵部。词条出现也不自动证明分词边界与当前义项。

无完整证据时 `strictAntithesis=unverified`、`contextualPronunciation=unverified`、`publishAsVerified=false`。即使只见一个参考表韵部，也仍是 `reference_only`，不是语境读音已审定。

规则依据：教育部《国语辞典简编本》对仗条说明音律、句法、词性对应：
https://dict.concised.moe.edu.tw/dictView.jsp?ID=9547&la=0&powerMode=0

现代词条来源保存在 `data/quality_v1/reading_hints.json`，含少年、处处、远近、音乐、快乐。原平水韵录文、来源版本与许可仍使用 `data/reference_v02/`；没有修改冻结韵表。

## 实验协议与复现

每种诗体固定起式、首个可用韵部、beam=32、variation=0.8。各取32个任务，每个任务生成4首：第一首作单次基线；四首中原统计分最高者作等生成预算对照；同四首作审校重排。总计64个任务、256首。没有人工改字或挑选“最好看的例子”。

固定代理分为原统计平均分减：未获支持的交界字串比例×0.4、无句法假设句比例×0.3、无可能结构匹配的中联比例×0.5、多韵部字位比例×0.2。权重未根据本批结果调参；这不是外部预注册实验。相同资源与输入可重放。

```sh
python -m pip install -r requirements.txt
python scripts/build_web_data.py
python scripts/build_web_seven.py
PYTHONPATH=src python -m unittest discover -s tests_quality -v
mkdir -p /tmp/quality
node scripts/sample_quality_candidates.cjs /tmp/quality/samples.jsonl
python scripts/run_quality_experiment.py --samples /tmp/quality/samples.jsonl --output /tmp/quality/review
```

输出 `audit.jsonl` 为逐候选证据；`report.json` 为对照；`blind_review.json` 对同四首的原分最高与审校重排做等预算匿名比较，隐去方法；`blind_key.json` 保存对应关系，评审时不得一起给评审者。程序拒绝覆盖已有样本文件／结果目录。当前独立人工评分数是 **0**，空白评分不被计成通过。

## 首轮实际结果

生成基线：提交 `956502c5d74a8911d2ac98ec8e14d07c04b6ca7f` 的线上引擎与数据。全部256首通过独立 Python 字数、基本平仄、韵脚、重字及当前训练原句排除检查；这不是严格律诗认证。

每首24个交界字串中，未获训练支持的平均数：

| 诗体 | 单次基线 | 同预算原分最高 | 审校重排 |
| --- | ---: | ---: | ---: |
| 五言 | 10.9375 | 10.0625 | 9.6250 |
| 七言 | 15.0000 | 14.1875 | 13.65625 |

这些指标本来就参与选优，不能当作独立文学质量提升证据。相比原分最高对照的改善也仅是代理指标。

更重要的负结果：本批三个选择策略都没有检出完整、明确结构对齐的中间联。小词表覆盖极低：单次基线平均每首五言仅0.5625句、七言0句有句法假设。**这表明审校词表／解析能力不足，不证明所有诗都不对仗。** 对仗项在这批候选的实际重排中没有贡献，不应据此上线“严格对仗”开关。

单次基线五言1280个字位中171个属于多个参考韵部；七言1792个字位中215个。它们是待消歧字位，不是已证实的读音错误。包括“還”可同为平声而跨韵部、“少”可同为仄声而对应不同读法。现代“少年 shào nián”提示不能单独完成历史读音认证。

本地175项既有Python测试及12项新增边界测试通过。新增CI独立重建数据、重放256首、保存审校与盲评产物；远端状态以实际运行结果为准。

## 后续优先级

**P0：改进生成单位和证据，不堆叠伪质量分。** 针对当前真实词块补全逐词多义项、语法角色与出处；不能把固定4+3截取当成已验证分词。中间联应按可替换词组／句法骨架联合构造，不能只在已成句候选中补一个词性分就称严格对仗。所有句子内容仍由程序选择。

**P0：历史音义绑定。** 每条读音证据需要文本版本、语境范围、词边界、义项、历史读音／韵部同一记录、出处与复核状态。只有现代词音或字表唯一归部不足以放行。不能为满足平仄临时挑一个读音。

**P1：文学评价。** 用未参与规则迭代的种子／样本生成匿名配对，分别评句意通顺、全诗连贯、意象关系、对仗；允许平局与无法判断。自动代理指标只作诊断，不能替代该评价。当前盲评包为开发材料，不再充当未来独立最终测试。

所有阶段保留来源散列、原文、参数、失败项和负结果。达到证据门槛前，不更新线上默认评分、不把本切片列为文学质量已提高。
