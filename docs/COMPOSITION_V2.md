# 词组共构 v2：上线说明与复核边界

入口：`composition.html`，引擎：`verseloom.phrase-composition.v2`。这是此前离线更新包中的独立词组组合实现；与已存在的 `quality.html` / `verseloom.quality-words.v1` 并行保留，不覆盖后者或旧候选句生成器。根 README 提供在线入口和完整构建命令。

## 生成机制

数据是词项、拟用义项、历史读音记录和训练语言统计，不含可被抽中的完整输出句。每个词项最多两个字；词项须具有训练出处，未决读音或韵部映射不准入。原训练整句仅以哈希用于排除，不作为诗句模板。

五言可使用主谓宾与方位状态结构，七言加入场景、时段或状态修饰。中间两联先联合选择上下句，匹配词组长度、词类、角色与声明的语义类别，再构造外侧两联。搜索过程中保留多分支；最终选择发生在完整八句之间，不预定任何一句。框架、词汇和语义条件仍是有限的，不称为开放语言空间的无限创作。

读音策略先于格律选择：每条记录保留《广韵》字头、反切、音韵地位、原释义、释义参照路径和拟用义项。追查上同／下同只取得释义，不继承参照条目的音韵地位。区分平、上、去、入，平水韵关系只在声明的唯一兼容条件下准入；并不宣称已经完成所有历史韵目交叉映射或语境专家审定。

## 数据与现有工作保护

只统计旧 `train` 和新增 `train_candidate`，开发、测试及隔离材料不供训练。来源固定提交与文件散列延续数据启动流程。原先 200 首、400 组开发任务的人工复核状态不因本模式上线而自动升级；没有独立金标或文学评分就不记录为通过。

本版构建预期覆盖 13,810 首形状候选文本、408 个准入词项，排除 156 个设计词项；真实计数由 `build_composition_v2.py` 输出并保存在构建报告。词项语义与框架由助手设计，不是独立标注成果。新提交没有修改旧的原诗、韵表、冻结模型与首诗记录。

## 交互约定

- 初始不填入诗稿。默认春／薄暮是场景设置，不是固定内容。
- 五言和七言各维护近期成功诗稿。手动种子不暗用会话历史；复现沿用原始参数快照。
- 自动模式换种子，并排除最近八首的首句。随机不保证不同种子永不产生重复结果。
- 可取消 Worker 或主线程计算；取消不填入存档结果。找不到解时保留失败状态，不放宽规则。
- 点选诗句显示词项、角色、语料出处、字书条目和参照路径。下载 JSON 保留输入、来源、约束结果及失败诊断。

## 检验和发布

`tests_composition/` 检验读音候选与释义参照边界、来源身份、无固定句接口、种子回放、全部句位变化、Worker、取消及界面事件。`evaluate_composition_v2.cjs` 固定配置生成原样五言／七言样本，`audit_composition_v2.py` 用独立 Python 实现核对声明规则。

Pages 工作流先重建数据并逐字节比较，再执行新增测试，打包在线与单文件版本。`build_composition_site.py` 在打包后的首页加入明确入口并生成 `release.json`，最后重新计算整个站点的文件清单。上线检查绑定本次清单和提交，下载正式网址的代码、数据与页面，执行两种诗体并检查精确复现。

线上检查返回 `browserUIExercised=false`：HTTP 资源和 Node 执行通过，不冒充 Chrome／Safari 实际按钮或排版测试。测试和部署状态以对应提交的 Actions 为准，不把文档中的预期作为已完成结果。

## 已知局限

此前离线开发探针对四季×四时段×两种诗体的 32 组固定配置得到 28 组成篇，4 组七言返回无解；该历史结果不是所有参数的覆盖保证。保留 `probe_composition_contexts_v2.cjs` 以便复算，不用重试筛选掩盖失败。

机械结构匹配不认证工对、无合掌、典故适当、全文连贯或文学价值。来源关联的读音策略不等于独立语境认证。词项映射、限制和释义解释仍需复核。`strictAntithesisCertified`、`contextualPronunciationCertified`、`literaryQualityCertified` 均保持 false。不得由生成成功或测试通过直接改成 true。
