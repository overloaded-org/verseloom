# 随机种子与首句多样性

## 直接使用

网页默认开启「每次生成自动换种子」与「避开近期首句与起首词块」，探索强度 0.8。每次点击由浏览器选取一个可见的 uint32 种子，然后在合法候选内执行搜索；不使用模型 API，也不把存档诗随机轮播。

自动模式避开当前标签页最近 8 个成功诗稿的首句、最近 4 个首句的起首二字。首次也避开页面上显示的存档首句。历史仅在本标签页内存中，刷新会清空，不上传、不跨标签页同步。复现、取消和失败不增加历史。

固定种子：取消自动换种子。这时不应用近期历史，以保证相同版本、数据、种子及其余设置产生相同结果。点击「复现这首（原参数）」则使用该诗当次完整参数，包括当时的历史快照，不抽新种子。JSON 同时导出种子、参数、历史、引擎版本、数据 SHA、逐句评分及尝试轨迹。只复制一个种子，并不足以在自动去重模式下复现。

探索强度为 0 且历史为空时，逐模板路径、分数与原 v0.6 首诗保持一致。「恢复原版配置」关闭自动换种子和探索，并清空本页历史。

## 为什么不能只换种子

原版确定性 beam 总是优先同一高分路径。首句不入韵时，更换韵部也不会更换首句池。加入有限分数扰动可以改变全诗，却仍可能让少数高分首句和二字开头占据多数结果。因此分别检查全诗、首句、起首二字，而不把「全诗不同」当成「开头足够多样」。

## 算法 `verseloom.seeded-openings.v2`

1. 各模板先应用原平仄、韵部候选池，并排除明确提供的近期首句及起首二字。
2. 在剩余开头中，以最高语言统计分为基准保留差距不超过 0.8 的句子；按前二字分组，最多保留 16 组，每组至多 3 句。组权重按该组最佳句的统计分计算，不因同一开头拥有更多后缀而增加抽样份额。
3. 以种子驱动的稳定整数混合值，按 softmax 权重先抽一组，再抽组内一句。温度为 `max(0.2, variation)`。先固定这句，再组织后七句，避免最后一步最高分排序重新把所有首句压回一个。
4. 后续 beam 评分加入每个「模板、行号、候选句」独立确定的有界扰动，幅度小于探索强度。原始统计分 `score` 不含扰动，探索排序分 `selectionScore` 单列。未声称它是诗歌概率或文学评分。
5. 若选定首句无法完成八句，排除本次失败首句后重新抽样；每模板最多 8 次，采用第一条完整路径。所有失败与成功的行级计数记录在 `templateSummaries[].openingAttempts`。始终保留原格律和近期去重约束；穷尽有限尝试仍无解就明确返回 `infeasible`，不静默回退到旧诗。

该方法是项目内的分层抽样加启发式搜索，不是全局最优算法，也不是声称从整诗概率分布精确采样的 Stochastic Beam Search。候选语言分数与语料均未重训、未更改；其文学质量、语境读音和对仗仍未得到认证。

## 验证与范围

```bash
python3 scripts/build_web_data.py
node --test --test-reporter=spec tests_web/engine.test.cjs
node scripts/audit_opening_diversity.cjs /tmp/verseloom-opening-audit.json
```

审计固定 `L5-Z-R0`、原默认韵部、beam 32，使用种子 0..63，比较关闭探索、开启探索但不使用历史、开启探索及近期去重三组。会话从可见存档首句开始；不挑选样本。汇总见 `results/seeded_openings_v2/receipt.json`，完整逐次诗稿由审计命令生成。原始目标统计分也报告，避免把多样性提升误报为质量提升。

连续 64 次自动模式得到 64 首不同诗、44 个不同首句、20 个不同起首二字。最近 8 个首句内重用为 0 次，最近 4 个起首二字内重用为 0 次。不同窗口之间仍出现重复，故不能宣称永不重复。这个有限工程样例不是对所有种子或文学质量的统计推断。

网页测试包括同种子与完整历史复现、种子边界、原版结果保真、候选遍历顺序不变性、取消、Worker 等价、12 韵部×4 模板及历史耗尽。UI 事件测试使用轻量 DOM 模拟，其中一项接入真实引擎执行连续生成和复现；并非真实浏览器视觉／兼容性测试。

实现参考：浏览器取种子使用 Web Crypto 的 `getRandomValues`（https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues）。本项目的有限分层抽样与序列精确无放回采样要区分，后者参见 Kool 等（2019，https://proceedings.mlr.press/v97/kool19a.html）。
