# v0.2：当前结果与项目决策

日期：2026-10-29。算法正确性已在声明范围内验证；文学质量状态仍为 **NOT_TRAINED / NOT_EVALUATED**。

## 找到并保留的核心

基本声律文法生成完整模板；使用语境明确的字位候选；外层枚举有限模板与统一韵部；四联局部卷积评分可加时，由精确DP组合整首最优。此范围有明确递推与证明，见ALGORITHM_v0.2.md。它不是诗人认知机制的证据，也不是文学价值已被完全量化的结论。

## 本次实际执行

- 84项风险测试通过，失败0、错误0；Python 3.12.14、NumPy 2.3.5。
- 五言、七言各4个基本模板；首句入韵没有错误地传递到第5句。窄放宽审核与严格全篇求解使用不同的明确profile。
- 单联4组核对：5/7字长×2种子；每位置上下各2候选；1024或16384种组合由原始LocalConvScorer穷举。选中结果的原始分数均达最优，分解偏差最大1.39e-16。
- 全篇2组核对：完整8×5与8×7，每题2模板×2韵部、384种原始矩阵、16种可行矩阵；总共768种完整矩阵逐联原模型评分。选中结果均达全域最优；外层每配置的分数也核对，最大偏差4.45e-16。容差1e-12。
- 独立审查发现并修复局部因子累计的正、负溢出问题；保留原始发现运行，在discovery_v02_reviewed中保存修复后重跑。不能把两次重复配置当作两份独立效果证据。
- 正式合成机制集：60开发题+240测试题，四类问题；两策略×四预算，共2400次运行。全部300题合法可达域与全域oracle一致，全部2400条轨迹重执行一致。
- 106部固定来源可离线重建并逐字节核对；衍生文件校验通过。

## 没有通过的搜索策略

主预算32次尝试、240测试题：FIFO平均归一化最优差距0.1337455，priority为0.1184303；相对下降11.45%，95%配对重采样区间[1.66%,19.51%]。预设至少20%收益门未通过。

local_trap类别从0.2468009变成0.2984904，恶化0.0516895，超过预设0.05类别退步门槛。结论：**DO_NOT_PROMOTE_PRIORITY_AS_DEFAULT**。

决定使用可分解目标的精确求解；通用搜索比较显式指定FIFO。为了复现本地冻结实验，历史matrix.py函数的默认签名保持不动。机制配置为运行前本地冻结，不是外部预注册；这些测试题现已暴露，后续调整不能用同一题集作为独立确认。

所有成员记录均为source_candidate_needs_context，不是verified。已记录5个校勘议题，包括先/啼缺漏、頹/龍的归属疑点和部名惯例；自动校订0项。结构齐全不意味着内容无误。未知字返回unknown，不能据此断言历史读音不存在。

## 使用边界

`verified=True`是调用者对读音证据的声明，程序不会自行证明该证据可信。任何未验证、多读音或未知候选在过滤前返回needs_reading_review；缺候选返回infeasible。完整求解仅使用严格基本模板，不等于审核模块的common_prefix覆盖。

全篇最优依赖固定模板/韵部后四联独立和分数可加；新增全局语义、禁重字或更长词跨度，须显式扩状态或更换求解器。局部最优不能经事后全局检查变成更广约束下的最优证书。数学证明基于精确算术；实际浮点证据采用1e-12容差。

实现缓存全部局部因子并保存前缀路径，前沿状态数不代表总内存。跨平台浮点重放尚未验证；历史trace是可检查的运行记录，不是第三方签名。
