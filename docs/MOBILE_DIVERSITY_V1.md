# 移动端与算法重复偏差修复

本切片同时推进移动端体验和无人工内容的生成研究。基线为 `8b77008efb9600cd59ade103b7f4c6985143e7c5`；不修改训练语料、词汇准入、历史字书、声律规则或人工词表，不禁用投诉中的特定词，不填入替换诗句。

## 为什么“美少年”“虎眠”反复出现

问题主要在旧首页候选句基线，不应归因到没有同一候选池的新实验模式。冻结五言数据里，“美少年”后三字片段训练出现2次，组合为8条候选句；“見虎眠”出现2次，组合为12条候选句。它们均在PPZZP、下平一先的候选组。原auto择韵始终取首个可行韵部，随机只在固定韵部内搜索；高分片段经多次组合后获得过多机会。原近期机制主要避首句，没有覆盖后七句的片段复用。

修复：探索强度大于0时，auto韵部由种子在可行韵部间探索；指定韵部仍受尊重；强度0保持历史确定性优化。新增完整诗稿近期记录，以全部二/三字片段的近期出现次数作软惩罚。每片段每首只计一次，惩罚为每句mean(log1p(count))×0.5，不涉及词义/题材白黑名单。引擎v4保留原统计score，selectionScore另扣该惩罚，逐句记录historyPenalty。
