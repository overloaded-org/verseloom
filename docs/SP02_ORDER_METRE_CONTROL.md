# 同声律条件下，模型能否认回原诗的联序？

这是[全句位实验](SP02_ALL_POSITIONS_AND_ORDER_V1.md)的关键对照，**以下面的解释为准**。研究对象是来源诗的次序，不是程序生成诗的文学合格率。两个互换任务不能横向比较命中率。

## 为什么要换试题

颔联与颈联直接交换虽不改字，却会改变它们所在格律位置。只查项目韵表中平仄可判的字（覆盖约79%字位），对每种模板计算最少不合数，不读意义，也不训练。在原序与颔颈互换的二选一中，该规则五言认对93.60%，七言97.92%；平仄损失打平的只剩五言28首、七言5首。不能用那项对照证明模型学会篇章意脉。这是测题存在捷径，不是已经证明某个学习模型使用了捷径。

改为互换**颔联与尾联**：原序1,2,3,4,5,6,7,8，对照1,2,7,8,5,6,3,4。保持每副联的内部顺序。程序逐项断言，仓库的五言与七言共八套模板中，3与7、4与8的每一种允许平仄序列及其押韵要求都相同。原诗与交换版因此有相同的声律匹配代价、相同的押韵位置与韵脚集合；不需要认定原诗符合全部传统规范。任何只按这套模板计分的系统，在该任务均打平。

## 本地实测

训练2,048首（五、七言各1,024，一诗族一首）；开发1,464首（五言792、七言672），与训练诗族无交集。使用原有八种关系特征，比较七个接续位置；没有加入手写词表、内容示例或叙事路线。比较原序和交换序，打平计半分；先在诗族内平均，再按诗族平均，随机基准50%。

| 评分或对照 | 五言 | 七言 |
|---|---:|---:|
| 原有通用接续评分，同一任务 | 62.58% | 67.69% |
| 从颔颈互换任务直接迁移的联序模型 | 46.96% | 46.85% |
| 直接在同声律互换任务上训练 | **65.57%** | **72.62%** |
| 同任务重训，去掉中联词段对齐特征 | 57.74% | 64.00% |
| 同任务重训，只留2→3、4→5、6→7三处 | 51.30% | 55.92% |

同声律专项相对原有通用评分，五言+2.99个百分点（配对95%区间−0.67至+6.76），七言+4.92（+1.23至+8.73）。去掉词段跨度对齐再训，七言下降8.62个百分点（+5.84至+11.54为完整模型相对去对齐模型之差）。七言只留三个跨联位置仍高于50%（95%区间52.08%–59.62%）；这说明有可用统计信号，但也说明72.62%不能解读为语义连贯率。单独的对齐特征不等于专家认可的工对。

这些是同一开发集上的探索性对照，按诗族重采样2,000次、未作多重检验校正。相同声律不排除结尾惯用语、句法或平行结构等位置线索。没有独立文学评分，不读取最终保留集，不替换线上算法。**下一次在程序自产、同韵同起式的候选诗上比较原评分与整诗排序，并匿名评联间承接和收束，而不是再把原诗复原率当作品质分。**

## 复现

仓库脚本：`scripts/check_order_meter_confound.py`、`scripts/check_continuation_equal_meter.py`。对 `continuation.yml` 生成的同一份模型、语料及 `order-probe` 产物执行：

```sh
src=output/continuation-source/run/candidate_poems.jsonl
exp=output/continuation-v1
python scripts/check_order_meter_confound.py --model web/induced-data.js --corpus "$src" --order "$exp/order-probe" --out "$exp/order-meter-check"
OPENBLAS_NUM_THREADS=1 python scripts/check_continuation_equal_meter.py --model web/induced-data.js --corpus "$src" --ranker "$exp/ranker.json" --order "$exp/order-probe/report.json" --out "$exp/equal-meter-order"
```
