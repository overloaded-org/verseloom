# v0.5 上下文—二字片段匹配：独立方法评审

日期：2026-10-29。评审对象为尚未读取独立确认集的 train/dev 开发实验。本文件记录评审建议和已接受的设计；实际参数、训练预算与输入身份以运行前冻结的 v0.5 配置和 manifest 为准，不把本文件当作已完成结果。

## 1. 本轮问题与固定边界

本轮要判断：学习可见上下文与完整二字片段的匹配矩阵，能否在固定宽词表和 K=16 下，提供可重复、确实依赖上下文的开发集检索信号。

- 仍使用 v0.3 的 2,502 首 train、547 首 dev。旧 test 行在 JSON 解码前跳过；不得打开 v0.4 confirmation 的任务、预测或结果文件。
- 宽候选 W 固定为旧 train 全部八句内相邻二字、出现至少两次、按句长分池。五言 10,375 项，七言 1,504 项；保留原字形，不跨句取片段，不加入开发答案。
- 查询只含句长、完整上句、下句可见后缀和固定遮蔽位置。题名、作者、原始完整下句、目标、诗篇与诗族 ID 不进入模型。
- 目标仍是下句首二字的来源原文。词表外训练目标不能偷偷加入 W；可以在训练损失中排除，但必须报告排除数。全部 dev 题仍进入分母，词表外目标计零。
- 首版不训练或调参统计分数与神经分数的混合器。纯学习检索器与固定 v0.4 开发选中宽检索器直接比较。v0.4 基线的权重来自其已冻结开发选择，不通过确认结果重新选择。

这仍是来源文本复原检索，不是严格合律标签、词法分词金标或文学质量评价。本轮匹配分数不自动继承既有全诗局部动态规划的可加性证明。

## 2. 匹配矩阵和训练目标

对同一句长的一批查询，构造查询矩阵 Q 和该句长全部候选矩阵 E：

\[
S_{bc}=\tau^{-1}\langle \bar Q_b,\bar E_c\rangle,\qquad
\mathcal L=-\frac1B\sum_b\log\frac{\exp S_{b,y_b}}{\sum_{c\in W}\exp S_{bc}}.
\]

已接受的首版选择是按句长分池的**全候选 softmax**，不采用另有采样分布的 in-batch negatives，也不把同一目标在批内的重复出现当成互斥负例。不同长度批次使用各自完整 W；混合长度的更新若拆成子批，损失必须按样本数加权，且只能算一次参数更新。

主分数使用归一化 Q/E 和固定温度，不设候选独立 bias，也不设按候选 ID 任意查表的独立表示。候选编码由两个字符生成，必须保留左右次序，例如分别投影或拼接两字表示；无位置的二字均值无法区分交换顺序的片段。

温度、向量维数、卷积通道、归一化 epsilon、优化器及其全部参数须在任何 dev 评分之前冻结。归一化要写明精确公式及导数；零向量、UNK 和遮蔽输入不能产生非有限值。无候选 bias 或向量归一化都不能单独证明模型没有学到频率偏好，仍需下文诊断。

候选 E 在其参数更新后必须重新编码；不能把过期缓存用于下一步全 softmax，或在未声明的情况下停止候选分支梯度。共享字符参数需要累加查询分支、候选分支以及重复字符出现的全部梯度。

## 3. 四个训练臂和配对预算

| 训练臂 | 可见来源 | 横向窗口 | 解释 |
|---|---|---:|---|
| full3 | 上句与下句后缀 | 3 | 主学习检索器 |
| full1 | 上句与下句后缀 | 1 | 局部感受野对照，尽量匹配核心参数量 |
| upper-only3 | 仅上句 | 3 | 在训练与评价时均屏蔽后缀内容 |
| suffix-only3 | 仅下句后缀 | 3 | 在训练与评价时均屏蔽上句内容 |

单来源臂必须在训练时就移除另一来源，不能只在完整模型推理时删输入后称为同等训练对照。输入槽位、长度和固定位置特征可以保留，但内容屏蔽的精确规则必须冻结。full1 的核心与总参数量都要报告；若不能精确匹配，结论注明剩余容量差异，不能把全部差值归给卷积窗口。

三个固定种子使用同一可训练任务集合及同一采样规则，随机顺序因种子而异；同一种子的四个训练臂采用完全相同的任务与句长批次安排。相同种子下，共享结构的候选编码器与字符初始化应尽量相同；不同训练臂不得共享可变优化器状态。

目前计划每 run 1,200 次 optimizer updates、batch 32，在 400/800/1,200 次评估检查点，最终预算可在**只用训练数据的吞吐检查后、任何 dev 评分前**确定。吞吐试跑使用的更新与样本呈现要另外计入工程计算成本，不能悄悄并入或漏掉。正式记录每个 run 的实际更新数、批次数、样本呈现数、不同任务数和不同诗族数，不把重复采样数说成完整训练了若干遍数据。

## 4. 共同检查点选择

每个臂在同一检查点先对三个种子的逐题命中取平均，再在诗族内平均，最后各族等权。用精确有理数比较全部 dev 题的 R@16；同分选最早检查点。每臂只选一个共同更新步数，不分别挑各 seed 的最佳轮次，也不挑最佳 seed。

开发报告必须公开全部臂、全部种子、全部检查点的主指标。三种子均值衡量的是固定三个随机运行的平均表现，不能直接称为一个三模型集成检索器；如果后续拟部署融合排名，需要另行定义并冻结融合规则。

检查点使用不可覆盖的更新编号文件，如 `update_0400.npz`。选择记录引用具体文件、SHA、arm、seed 和模型内部 step_count，不再通过可能被后续写入覆盖的通用 `selected.npz` 路径传递身份。加载后检查身份及步数再评分。保存和加载还需保留可重放的优化器状态。

## 5. 防止频率伪信号的诊断

至少保留以下无额外学习的比较：

1. 固定 v0.4 选中宽池检索器：A=B=0.25，原字符统计模型保持不变。
2. 训练下句首二字的目标频次排序：在 W 内排序，未作过正例的候选频次为零，同分按词面排序。
3. 训练全部句内相邻二字的 W 频次排序：同分按词面排序。
4. full3 同句长错配上下文诊断；可附加全部内容遮蔽的推理诊断，后者不再训练。

W 来源比“下句首二字正例”更宽。因此要保存每个候选的 train-prefix-positive count，并报告 dev 目标属于“训练中作过正例”“W 内但从未作过正例”“W 外”三类的规模和检索表现。第二类在全 softmax 中可能只有负例梯度，这是监督任务分布限制，不能在失败时忽略。

### 错配上下文

错配映射在训练和检查点选择前固定，只使用 task ID、句长、诗族 ID 与 visible-query hash。推荐在每个句长内按固定盐排序，选择第一个使全部配对满足约束的循环位移，生成一一置换。每题的 donor 必须来自不同诗族且具有不同可见查询 hash。相同映射用于全部种子和训练臂。

目标保持原题目标，只用另一题的可见上下文评分。不得查看目标以避开“两个题的答案碰巧相同”，不得根据命中变化挑选映射，也不得把 donor 的完整下句或目标传入查询。改变或移除目标字段应完全不影响映射；映射还必须保持相同句长、全覆盖和一一性。

固定候选频率排序在真实／错配查询之间完全不变，所以此诊断能够揭示纯候选先验主导的结果。仅有排名变化不构成有效上下文信号；还要看真实查询相对错配查询的来源原文召回差。

## 6. 是否值得新独立确认

建议在运行前冻结以下**开发资源分配门**，全部满足才优先建立新的独立确认：

- full3 在其共同选中检查点的三种子平均诗族 R@16，相对固定 v0.4 强基线增加至少 0.02，即 2 个百分点。
- full3 三个种子各自的主指标均高于该强基线，不由单一幸运种子支撑均值。
- full3 三种子平均真实查询 R@16，较固定错配查询提高至少 0.01，即 1 个百分点；逐 seed 差值全部公开。
- 训练、数据身份、梯度、完整候选排名、检查点身份和无目标泄漏的工程核验通过。

1 个百分点的错配门是事先选定的工程阈值，不是统计学定律。即使通过上述门，也只是值得投入独立确认，不能宣布泛化改善。dev 已反复用于开发；在其上报告的置信区间只能作描述，不能消除选择偏差。若不通过，报告未通过的具体条件，保留全部结果，不追加训练、改温度或重选种子后仍称同一冻结实验。

如后续进入新确认，必须先确定要确认的是三随机运行平均、一个固定种子模型还是明确的集成器；冻结该决策与检查点后使用新来源及新族隔离规则。旧 test 和 v0.4 confirmation 均不能充当新的确认集。

## 7. 最小而有意义的核验

- 全 softmax 的独立小词表标量 oracle；真实候选名次与完整矩阵排序一致，包含词面同分和 OOV。
- 有选择的中心差分梯度检查，覆盖查询卷积、候选编码、归一化、共享字符参数及重复字符梯度累加；不使用解析梯度自身作 oracle。
- upper-only 对后缀修改不敏感、suffix-only 对上句修改不敏感；完整臂改变目标／作者／题名不应改变评分。
- 错配的 target 无关性、一一性、同长度、异诗族、异查询和复现性。
- 共同检查点选择以所有 seed 和完整 dev 分母为准；精确同分选早，不使用 seed 最优包络。
- 模型内部步数、文件名、保存 SHA 与选择记录一致；改动冻结输入或模型字节应在评分前失败。
- 原始 Q 与 E 的显式点积复核批量分数及候选名次；全部 dev 指标从逐题结果独立重算。

独立结果审查仅新增审核记录，保留训练、选择和诊断原件。任何实际完整性异常要保存原件并单列恢复成本，不能删掉失败记录后只交付最后成功的一次。
