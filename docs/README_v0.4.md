# VerseMatrix Lab v0.4

声律矩阵、局部词片段评分与有限候选精确组织的研究工程。当前已实现有范围的格律文法和可加目标求解；尚未证明能够生成高质量律诗。

## 当前结论

v0.4 在新的诗族隔离文本上验证了扩大候选与局部关联检索。**这版检索器未通过晋级门。** 词表覆盖扩大，没有转化成足够稳定的前16候选召回优势。v0.3 的小型卷积未晋级结论保持不变；本轮新神经训练更新为0。

| 新确认集方案 | 诗族等权 recall@16 | 题目 micro recall@16 | 原文找回题数 |
|---|---:|---:|---:|
| 原窄池统计 | 3.0029% | 3.0057% | 63 / 2096 |
| 宽池原统计 | 3.3447% | 3.2920% | 69 / 2096 |
| 开发选中关联方案 | 3.3447% | 3.2920% | 69 / 2096 |

主比较为选中方案减原窄池：+0.3418个百分点，95%配对诗族区间[-0.2441,+0.9290]个百分点。未满足预定的点估计至少+2个百分点且区间下界大于0。次要比较、其他K、top1和MRR不能替换主判断。R@16是原文是否在候选池中，不是top1正确率或文学质量。

## 本轮做了什么

- 训练保持旧train的2502首；开发保持旧dev的547首/2188题。旧test在检索运行器中于JSON解码前跳过。
- 窄候选来自训练偶数句首二字，频次至少2：五言1317、七言97。宽候选来自全部训练句内相邻二字，频次至少2：五言10375、七言1504。两者按句长分池。
- 评分保持原双向字符统计S，增加上下对应二字关联A、候选与可见后缀首二字的四字搭配关联B：`S + a*A + b*B`。两个权重各取0、0.25、0.5、1，共16方案。
- 按dev诗族等权R@16精确有理数选择，9个参数点并列最佳，按固定网格顺序选A=B=0.25。并非发现唯一最佳参数。
- 选择、源码、输入、候选及关联计数SHA冻结后，再确认一次。确认前从开发逐题记录重算选择，三方一致才允许开始。

## 新确认集及边界

固定Git提交 `b8594f81a89752241442f2ce267d6f66f96704ee` 的唐诗分片10000至19000共10003条记录。八句等长且纯CJK的记录4286条，去重后4284首。

把新文本和全部旧3579首联合建图；全文相同、共享整句或句内二字组集合Jaccard≥0.8连边，取传递闭包。排除与旧诗同分量的新诗183首（含38首旧精确文本）。剩余4101首/3997族按固定盐SHA排序，取前512族且整族保留，得到524首/2096题。五言1492题，七言604题。

形态筛选不等于严格律诗认证；表面诗族可能漏掉异体字或版本关系，作者可跨集，固定连续分片不是诗歌总体随机样本。所有目标是来源原文，不是优美措辞或诗意的金标。这个确认集现已暴露，不能验证后续调参。

## 具体失败机制

题目层面的词表覆盖从304/2096（14.50%）提高到727/2096（34.69%），新增423题的原文可供选择。但宽池原统计只新增命中20题，同时丢失14个旧命中，净增6。选中关联方案相对宽池新增3、损失3。

对于相同分数和同分规则，扩展词表W包含N时，旧候选的名次满足 `rank_W(w) >= rank_N(w)`。扩张会引入竞争者，不能自动提高旧候选名次。这个单调关系在304个旧词表内目标上全部成立。当前仍有658题是原文在宽词表内但未进前16，另有1369题在宽词表外。

正式确认后的有限开发诊断单列在 `results/dev_quota_v04/`：固定总输出16，给旧片段与互斥新增片段分配位置，只用旧dev比较全部10方案。配额网格内最佳为旧12/新4，dev诗族R@16为4.3430%，仍低于正式开发选中宽池的4.4250%。当前不优先推进配额独立确认；该探索不改变正式门槛、结果或默认方法。下一轮研究改为在固定宽词表和K=16下学习可见上下文与候选二字片段的匹配矩阵，先检查开发排序信号，再冻结新的独立确认。这个方向尚未验证有效。

## 算法与工程状态

- `prosody.py`：有明确适用范围的五/七言声律模板，保留首句入韵、粘对与参考读音边界。
- `factor_dp.py`、`verse_solver.py`：在给定候选域、允许读音与局部可加目标下精确组织；不是全篇语义或文学最优保证。
- `learned_conv.py`、`span_solver.py`：v0.3可训练局部卷积与完整二字成员约束；保留144项训练后DP与枚举核对。
- `retrieval.py`：训练专用片段资源、可解释A/B统计与快速基线；保持原标量分数和同分排名定义。
- `confirmation.py`：新旧联合诗族排除与固定整族确认选择。
- 当前140项工程测试通过。正式dev固定16题全窄池数值和完整排名精确一致；独立审核用原标量评分及独立Counter重算16道确认题、95032个宽候选、48套排名，全部一致。
- 所有确认行的来源、候选成员与报告指标已复核；420个指标切片及3个5000次bootstrap独立重算一致。完整审核范围及限制见 `results/retrieval_v04/independent_review.json`。

固定K仅固定输出池大小，不固定检索计算预算。本次运行共享宽池组件，再分别排序；每方案排序候选量与实际共享组件工作量分别记录，不能称为同计算预算胜出。

## 运行

需要Python 3.10+和NumPy；本轮实际环境为Python 3.12.14 / NumPy 2.3.5。严格数值重放宜使用同一运行环境。

```bash
python -m pip install -e .
python scripts/run_tests.py
python scripts/build_confirmation_v04.py --check
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python scripts/run_retrieval_v04.py dev --out results/retrieval_v04_replay
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python scripts/run_retrieval_v04.py confirm --out results/retrieval_v04_replay
python scripts/analyze_retrieval_v04.py --check
```

实验目录不可覆盖；确认开始记录也只能创建一次。已有结果的再次重放是工程复核，不是新的独立实验。
