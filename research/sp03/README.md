# SP-03 结项：能不能认出语序破坏和错接尾联？

**决定：保留语序检测器供研究，篇章模型未达到预定门槛；不接入默认生成。** 无题材输入、手写内容词、指定诗句或生成兜底。没有更改网页、既有搜索代码或语料。不能把本轮称作训练了整诗离散扩散模型或获得古典句法、工对、文学质量认证。

## 配对实验

在统计表训练和参数拟合之间按诗族隔离。8,433首用来计数，另2,875首训练四项句内、九项篇章特征的线性配对评分。五言758个、七言650个开发诗族代表（每诗体每族一首），未解码1,394首test_reserve或382首隔离材料。该开发集曾用于SP-02，不冒称新盲测。语料是八句形状候选，不全是专家认证的律诗。方法使用原文与控制扰动作为相对标签，不假定所有异序都写得更差；参见[文本顺序辨别任务](https://aclanthology.org/J08-1001/)。

| 按诗体内诗族等权，原文优先比例 | 五言 | 七言 |
|---|---:|---:|
| 同平仄换两个非句末字：模型 / 仅字位 | 84.79% / 70.23% | 89.12% / 71.84% |
| 新增相邻字对均见过：模型 / 仅字位 | 62.31% / 69.04% | 70.99% / 72.59% |
| 同诗颔联、尾联互换：模型 / 仅位置 | 77.70% / 77.04% | 80.77% / 81.23% |
| 同韵字跨诗互换尾联：模型 / 仅位置 | 57.08% / 50% | 63.64% / 50% |

句内共有10,358个原句–扰动对；不改用字、字数、句尾和参考平仄序列，不把平仄共识当作具体义项的读音认证。难例为460/226句；五言难例相对字位对照反而低6.73个百分点（95%诗族重抽样区间 -11.74 至 -1.63）。这个模型能抓字序异常，但未证明能辨所有别扭句。给定恰好一次换位，排除只有一个候选的简单复原题后，五/七言恢复原文率85.04%/84.35%，对应均匀选择42.63%/26.53%。

篇章判别不看每行最后一个字。原诗顺序实验保留全部八句并只交换第二、四联，不能保证每处平仄相同；只有3/0个严格可确认对位平仄一致的五/七言样本，故不作此子集结论。与仅位置模型的配对差分别为 +0.66pp（95%区间 -1.06 至 +2.37）/ -0.46pp（-2.62 至 +1.54）。跨诗互换只取同诗体、相同尾字的不同家族，以 A→A+B→B 对比 A→B+B→A，单纯的行位词频严格抵消。正确125/219与126/198对；均高于机会水平，但主实验无法证实超过位置线索，故不发布。区间是开发数据上的描述值，未作多重比较校正。

## 回到真正的程序生成结果

保留SP-02各8个种子的原初稿和四种修订，不再增加搜索预算。80个候选条目在各自组内去重后59种；对同一候选集排序，新旧首选五言换5/8次、七言换2/8次。逐项检查字数、平仄、同部不重韵、来源原句哈希排除及重字限制。种子0仍选“別有一條寒”和“天欲明歡喜見來”：有不含这些句子的程序稿可选，评分器仍未避开。7/16换稿不是7/16改善。没有独立文学评分。A/B读者材料和答案另外存放。
