# SP-04：真实对句能否帮助辨认错序？
研究结果保留，不改变 Pages。这里训练的是配对排序器，未训练扩散模型、未生成预写诗句，也没有新增禁词。

语料计数8,433首、参数拟合2,875首、开发代表1,408首（沿用上轮分割；不解码test_reserve）。从训练语料相邻分布归纳48个字类，增加跨一至两字的搭配，以及对句同列、邻列关系。48类不是人工词类标签。五、七言共21,177个拟合样本，按诗体与难度均衡加权。不在开发集调参。

实测（按诗族等权；以下为本地运行）：

| 原文优先比例 | 五言：SP03→SP04 | 七言：SP03→SP04 |
|---|---:|---:|
| 原难例（460 / 226） | 62.31%→81.44% | 70.99%→80.35% |
| 双边全部相邻字对均见过（201 / 64） | 81.93%→85.54% | 95.69%→90.52% |
| 全集（5225 / 5133） | 84.79%→88.53% | 89.12%→90.85% |

双边题对仅字位对照提高19.13pp [11.14,26.81] / 11.21pp [0.86,21.55]；对旧模型分别为 +3.61pp [-2.81,9.84] / -5.17pp [-12.07,0.00]。仅相对字位的事前研究门槛通过，不能说全面超越旧模型。旧定义只限定错序新增的字对，两边均可见的样本不保证更难。句对任务中，同句位、同末字配对原本上下句：177/183和160/162；单句得分在交叉分配中严格抵消。探索性对照不要求尾字相同，但不给评分器两个末字，且匹配两条候选下句所有偶数字位的明确平仄，得到216/226和158/159；两种题集不同，不能直接计算消融效应。它们都是原诗来源归属，不是专家工对判定。

对80份冻结程序候选（组内59种）重新排序，五言/七言各换2/8；第一种子仍保留“別有一條寒”“天欲明歡喜見來”。独立文学评价为0。下一步应取同一生成上下文及同韵同式的合法备选做匿名逐联比较，而非大量再造容易区分的错配。来源文本不作为生成候选，本轮完全没有线上写入。

离线复现：先解开SP03复现包，设置 OPENBLAS_NUM_THREADS=1 和 OMP_NUM_THREADS=1。Python3.13.5，numpy2.3.5、scipy1.17.0、scikit-learn1.8.0。运行 `python experiment.py <SP03目录> first` 和 `PYTHONHASHSEED=887 python experiment.py <SP03目录> replay`，再 `python audit.py first <SP03目录> replay`、`python meter_check.py <SP03目录> first extra`。逐项记录包括所有平局与失败结论。没有用人工批评的两个句子训练模型。
