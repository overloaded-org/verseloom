# v0.5 工程验证材料

`preflight/` 保留正式训练之前的吞吐预检脚本、冻结配置、抽样记录、原始 receipt 与 20 步检查点，均与原始文件逐字节相同；身份映射见 `preflight_copy_manifest.json`。原始记录中的 scratch 路径是执行时位置，未为重新打包而改写。

后续 `numeric_audit/` 如存在，只核查已选模型的矩阵分解、批次／单句及保存加载一致性，不新增训练或改变正式选择；独立数学前向与梯度 oracle 由另一位审查者提供。
